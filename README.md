About This Project

This portfolio was built from the ground up as part of the WEB101 curriculum. It serves as a dynamic and interactive resume, highlighting my hands-on technical projects and professional goals as an aspiring cybersecurity analyst.

Key Features

Responsive Design: The entire layout, including the header, uses modern CSS Flexbox to ensure a seamless experience on any device (desktop, tablet, or mobile).

Interactive Project Gallery: The "Featured Project" section includes an interactive image gallery built with vanilla JavaScript to walk visitors through the key steps of my mobile pentesting lab project.

Embedded Multimedia: The site features an embedded YouTube video to demonstrate project processes and links to detailed PDF documentation.

Dynamic Navigation: On-page links provide smooth scrolling to different sections of the portfolio, creating a fluid user experience.

Technologies Used

HTML5: For the core structure and content of the website.
